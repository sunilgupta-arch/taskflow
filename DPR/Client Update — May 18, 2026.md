# Client Update — May 18, 2026

## What's New

### Client Portal — Project Updates and Release History
When viewing a project in the portal workspace, there are now two additional tabs alongside the existing overview:

- **Updates** — shows the daily progress notes your team wrote for the project, with the author and date.
- **Releases** — shows every deployment and go-live event, including the version number, environment (development, staging, or production), who deployed it, and any release notes.

Both tabs load on demand so the portal stays fast.

---

## Bugs Fixed

### Workspace Loading Issue
When the admin workspace page loaded and no projects were set up yet, the loading spinner ran indefinitely with no message. This is now fixed — if there are no projects, the page correctly shows an empty state with a prompt to create the first project.

### Chat Message Box Invisible in Light Mode
Users with the interface set to light mode found the chat message input box had a black background, making it impossible to see what they were typing. This has been corrected — the message box now shows the proper light background in light mode.
