# Client Update — May 23, 2026

## What's New

### Downloads Portal — Share Software and Files with Your Team
A new **Downloads** section is now live on both the internal admin panel and the client portal.

**What it does:**
- Upload any software, utility, or file (up to 500 MB) so your entire team can access it from one place
- Files include a name, description, and version number so users always know what they're downloading
- A download counter shows how many times each file has been downloaded
- A live search bar lets users quickly find files by name, description, or who uploaded them

**Who can upload:**
- Internal side: Local Admin and Local Manager
- Client portal: Client Admin

**Who can download:**
Everyone on the team — no restrictions.

**Disabling a version (Admin only):**
If you want to retire an old version without deleting it permanently, the Admin can disable it. Disabled files stay in the list with a "Disabled" label but cannot be downloaded. They can be re-enabled at any time.

**How the storage works:**
When a file is uploaded it's saved instantly to the server — so your team can start downloading within seconds. In the background, the system also uploads a copy to Google Drive for safe long-term storage. After one day, the local server copy is automatically cleaned up to free up space, and all downloads from that point forward come directly from Drive. You don't need to do anything — this all happens automatically.

**Where to find it:**
- Internal admin side: **Tools → Downloads** (Admin/Manager), or the **Downloads** link in the left sidebar (all other users)
- Client portal: **Downloads** link in the left navigation
