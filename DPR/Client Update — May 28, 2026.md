# Client Update — May 28, 2026

## What's New

### Downloads — Public Access Page

Files in the Downloads section can now be made **publicly available** — meaning anyone with the link can download them without needing to log in.

**How it works:**
- A new page at `/downloads` lists all files marked as public — no account required to visit or download
- Each file card shows the file name, version, description, size, download count, and a Download button
- A search bar lets visitors filter files by name or description

**Marking a file as public:**
- When uploading, check the **"Make publicly available"** option on the upload form
- For existing files, Admin and Manager can toggle the **globe icon** button on any file in the Downloads list to make it public or private
- Files marked public show a cyan **"Public"** badge in the Downloads list

**Disabled files stay private:**
If a file is disabled, it will not appear on the public page even if it was marked public — disabled files are always hidden from the outside.

**Who can control public access:**
Internal Admin and Manager only.
