# Arden — Weekly Duty Checklist

Transcribed from `ArdenCounter_008318.pdf` (scanned 28 July 2026, Brother MFC-L5700DW, 6 pages).
Source was a scanned image with no extractable text — this file is the readable copy.

**Working week: Tuesday–Saturday.** Sunday and Monday are off.

Glossary as used in the document:

| Term | Meaning |
|------|---------|
| MTO | Made-to-order merchandise |
| F1–F9 | Floor / zone codes. F9 is the stock & staging area; F1E is the foyer area |
| 999 | Return / send-back location code |
| Comp kits | Complimentary customer kits |
| Scan gun | Barcode scanner — uploads must be "posted" by a manager |

---

## Daily Duties

*Applies every working day. The paper form has "DAY / DATE" at the top and "MGR" signature at the bottom.*

- [ ] Empty trash bins
- [ ] Check bathrooms for cleanliness and supplies
- [ ] Vacuum front foyer & sweep sidewalks
- [ ] Make sure coffee station is clean and stocked
- [ ] Stock refrigerator
- [ ] Make sure comp kits are stocked
- [ ] Walk around building and pick up any trash
- [ ] Blow off parking lot, if needed
- [ ] Scan any moves you make
- [ ] Keep F9 neat and orderly
- [ ] Wear your safety belt when moving furniture

---

## Evening Closing

*Identical block repeated at the bottom of every day's page.*

- [ ] Bay door closed and secured
- [ ] Make sure all tools are put away, including drill on charger, drill bits, box cutters, markers, etc.
- [ ] **Make sure scan gun is charging and manager posts**
- [ ] Make sure tablet is charging

---

## Tuesday

- [ ] Daily duties
- [ ] Pull all allocated pieces to F9 and scan
- [ ] Deep clean bathrooms, break room and stock room
- [ ] Mop bathrooms, break room and foyer area in F1E
- [ ] Prepare F9 for MTO
- [ ] Evening closing

---

## Wednesday — Truck Day

*Heaviest day. Everything below is in the order printed on the form.*

- [ ] Daily duties
- [ ] Help unload truck
- [ ] Line up MTO in the stock area with all barcodes facing the same direction
- [ ] Once truck is empty, scan MTO to F9 and compare the number of pieces to paperwork
- [ ] Upload the incoming MTO scan and have manager post it
- [ ] Scan all items going back to 999
- [ ] Help load the truck
- [ ] Check with manager to make sure nothing has been added
- [ ] Upload scan gun and have manager post it
- [ ] Move reserved items to the customer pick-up area, scan and upload gun
- [ ] Open all upholstery first and tag in F9
- [ ] Put them on the showroom as per the MTO
- [ ] Be sure all power pieces are plugged in and working
- [ ] Scan all items to location. Upload scan gun and have manager post
- [ ] Assemble the rest of MTO
- [ ] Evening closing

---

## Thursday

- [ ] Daily duties
- [ ] Finish up MTO (assembly, etc.)
- [ ] By the end of the day all MTO should be on the showroom, nothing in F9 for stock
- [ ] Vacuum F1, F2 and F3
- [ ] Evening closing

---

## Friday

- [ ] Daily duties
- [ ] Touch up and stock bathrooms and break room
- [ ] Vacuum F4, F5 and F6
- [ ] Blow off parking lot and sweep front walk
- [ ] Every other Friday, clean windows inside and out
- [ ] After 5 p.m. put out banners by road
- [ ] Evening closing

---

## Saturday

- [ ] Daily duties
- [ ] Pick ups
- [ ] Dust entire store including foyer
- [ ] As you dust, make sure lamps and reclining pieces are plugged in and working properly
- [ ] Evening closing
